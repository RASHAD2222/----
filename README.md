# ستوديو كروس هير فالورانت | Valorant Crosshair Studio 🎯

برنامج احترافي ومتكامل لتصميم ومعاينة وتوليد أكواد كروس هير لعبة فالورانت (Valorant Crosshairs) مع مكتبة ضخمة جاهزة لأشهر اللاعبين والأشكال الهندسية والمرحة.

---

## 🌟 المميزات الرئيسية

1. **🎨 مصمم تفاعلي دقيق (Crosshair Designer)**:
   - تحكم كامل بالخطوط الداخلية (Inner Lines) والخارجية (Outer Lines).
   - تحكم بنقطة المنتصف (Center Dot) وحجمها وشفافيتها.
   - تحكم بالتحديد الخارجي (Outlines) وسماكته وشفافيته.
   - دعم كامل لجميع ألوان فالورانت الرسمية (أبيض، أخضر، أخضر ليموني، أصفر، سيان، وردي، أحمر) بالإضافة لمنتقي ألوان مخصصة (Custom Hex Color).
   - إمكانية فصل الطول الرأسي عن الأفقي للخطوط.

2. **⚡ توليد واستيراد الأكواد (Code Generator & Importer)**:
   - **توليد الكود التلقائي**: يتولد كود فالورانت الرسمي لحظياً مع كل حركة تقوم بها.
   - **نسخ بنقرة واحدة**: زر مخصص لنسخ الكود ولصقه مباشرة في لعبة فالورانت (`Settings > Crosshair > Import Profile Code`).
   - **استيراد أي كود من اللعبة**: زر "استيراد كود" يمكنك من لصق أي كود فالورانت حقيقي لتحليله وعرضه وضبط جميع السلايدرات لمطابقته فوراً.

3. **🏆 مكتبة الجاهز (Presets Library)**:
   - **كروس هير المحترفين**: TenZ, Aspas, Boaster, ScreaM, Yay, Demon1, Derke, f0rsakeN, Chronicle, nAts, Cryocells, Tarik, Zekken.
   - **الأشكال الهندسية**: نقطة الهيد شوت، الصليب الكلاسيكي (CS:GO)، المربع المفرغ (Hollow Box)، الدائرة، الماسة، علامة الزائد (+)، الشوريكين (Ninja Star)، والشبكة المزدوجة.
   - **الأشكال المرحة والترول**: القلب (Heart)، الزهرة (Flower)، نظارة الطالب (Nerd Glasses)، الابتسامة (Smiley Face)، كرة البوكيمون (Pokeball)، وشخصية أمونغ آس (Among Us).

4. **💥 محاكاة إطلاق النار والارتداد (Recoil Simulation)**:
   - انقر بالفأرة على منطقة المعاينة أو اضغط على زر المسافة (Space) لاختبار إطلاق النار والارتداد الواقعي وتأثير Firing Error.
   - تأثير صوتي مميز لطلقات الأسلحة مع إمكانية الكتم/التشغيل.

5. **🖼️ بيئات المعاينة والتكبير**:
   - معاينة على خلفيات حقيقية: هدف التدريب (The Range Bot مع تحديد الرأس)، Ascent, Bind, Haven, Icebox، وخلفيات داكنة وفاتحة وشبكة بكسل.
   - مستويات تكبير دقيقة: 1x, 2x, 4x, 8x.

6. **💾 حفظ وتصدير**:
   - إمكانية حفظ تصاميمك الخاصة في المتصفح والرجوع إليها دائماً.
   - إمكانية تصدير الكروس هير كصورة PNG عالية الدقة بخلفية شفافة.

## 🚀 طريقة التشغيل

يمكنك تشغيل البرنامج بأي من الطرق التالية بكل سهولة:

### الطريقة الأولى (الأسهل والأسرع):
- انقر نقراً مزدوجاً على ملف **`start.bat`** وسيفتح التطبيق فوراً في متصفحك الافتراضي.
- أو افتح ملف **`index.html`** مباشرة في المتصفح (Chrome, Edge, Firefox, Brave).

### الطريقة الثانية (عبر السيرفر المحلي):
افتح موجه الأوامر (CMD أو PowerShell) في مجلد المشروع واكتب:
```bash
node server.js
```
وسيقوم السيرفر بالعمل وفتح `http://localhost:3000` تلقائياً.

## 🎮 كيفية استخدام الكود داخل لعبة فالورانت

1. في التطبيق، اضغط على زر **"📋 نسخ الكود"**.
2. افتح لعبة فالورانت واذهب إلى:
   - **الإعدادات (Settings)**
   - تبويب **الكروس هير (Crosshair)**
   - بجانب قائمة البروفايل، اضغط على أيقونة السهم لأسفل **(Import Profile Code)**
   - اضغط `Ctrl + V` للصق الكود ثم اضغط **Import**.
